# carpal 法務・コンプライアンス設計書

監査指摘 H-7 に対応。**本書は法的助言ではない**。実装・運用前に弁護士への確認を推奨。

## 1. 適用される主な法令・制度（日本）

| 法令・制度 | carpal への関わり |
|---|---|
| 個人情報保護法（APPI） | 位置情報は**要配慮個人情報**とまでは言えないが、行動履歴を構成するため個人情報に該当し得る。運転者と紐づく場合は特に注意 |
| 犯罪収益移転防止法・ストーカー規制法・軽犯罪法 | **同意なき人間追跡は違法**となり得る。GPS追跡器の不据付が刑事事件（軽犯罪法/不正アクセス/住居侵入の併合）になった判例あり |
| 道路運送車両法・貨物自動車運送事業法 | 事業用車両へのデジタコ/運行管理義務との関係（SaaS顧客が事業所の場合） |
| 各種条例 | 一部自治体のGPS追跡条例（例: 神奈川県） |

## 2. 同意管理設計

### 2.1 原則

```
SaaS提供者 (carpal運営)
   │ 利用規約で「運転者等の同意取得はテナントの責任」と義務付け
   ▼
テナント (事業所)
   │ 運転者へ説明・同意取得 → 同意記録を保持
   ▼
運転者 (ドライバー)
```

- **データフロー上の設計**: 位置情報はあくまで「車両（device）」に紐付け、個人（運転者）との紐付けはテナント側の任意運用とする。carpal 本体に運転者氏名を必須保存しない
- `devices` に `consent_confirmed_at`（テナントが同意取得済みと表明した日時）を持たせ、**登録時にテナントへ確認ダイアログを必須化**（UI: 「運転者から同意を得ていますか？」）

### 2.2 同意確認の実装位置

| フェーズ | 実装 |
|---|---|
| Phase 2-a | デバイス登録 API で `consent_confirmed=true` を必須パラメータ化 |
| Phase 2-d | 登録モーダルに同意確認チェックボックス＋規約リンク |

## 3. 利用規約・ポリシーの骨子（ドラフト目次）

1. 定義（テナント / デバイス / 位置情報）
2. テナントの義務（**運転者同意の取得・記録保持**、デバイスの適法な設置、第三者への追跡を許さない管理）
3. データ取扱い（取得項目、目的、保持期間、第三者提供の不実施、委託先）
4. 保持期間・削除: location 90日（既定、プランで変更可）、監査ログ 2年、テナント削除時30日以内に完全消去
5. 禁止事項（同意なき人物追跡、他テナント情報へのアクセス試行）
6. 免責・SLA（本書 §5）
7. 準拠法・管轄

## 4. データガバナンス

| 項目 | 設計 |
|---|---|
| 個人情報の特定 | 車両 ID（device_id）は原則匿名キー。IPアドレスは監査ログに保存（不正アクセス対処の正当な目的） |
| 暗号化 | 転送中: TLS（Phase 2 の Caddy / 8883）。保存中: PostgreSQL ボリュームのディスク暗号化（Proxmox LUKS）を Phase 2 で検討 |
| 越境移転 | 現状データは自宅サーバ（日本国内）のみ。海外 CDN/解析ツール追加時は見直し |
| テナント削除 | `DELETE /api/admin/tenants/{tid}/purge`: locations・devices・memberships を物理削除、監査ログは法定期間のみ保持後削除。削除完了をテナントへ証明書面で通知（Phase 3） |

## 5. SLA（SaaS 化時のドラフト）

| プラン | 可用性目標 | サポート |
|---|---|---|
| Free（現状・個人） | なし（best effort） | なし |
| Standard | 月間 99.0%（計測: API とライブ配信の応答性） | 営業日対応 |
| Enterprise | 月間 99.5%＋データ保持期間の選択 | 専任窓口 |

- 除外事由: 通信事業者障害、デバイス側の SIM/電波状況、計画メンテナンス（事前通知）
- **注意**: 自宅 Proxmox 1ホスト構成では SLA を採算保証できないため、有償プラン提供時は複数可用化（operations-design.md §4）が前提

## 6. サポート体制（SaaS 化時）

| 項目 | 内容 |
|---|---|
| 窓口 | メール＋チケット（Phase 3 で Zendesk 等の検討、初期はメールで可） |
| 対応時間 | Standard: 営業日 10-17時 / Enterprise: 24時間受付・返信 SLA 4時間 |
| 障害時連絡 | ステータスページ（Phase 3）＋テナント管理者へメール通知 |
| インシデント報告 | 個人情報漏えい等の事故時: 事実確認後**速やかに**報告（APPI の報告義務に従う） |
