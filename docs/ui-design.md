# carpal ブラウザUI設計書

対応システム設計書: `docs/design.md`

> **改訂 (2026-11)**: マルチテナント化（`docs/multi-tenant-design.md` §6）に伴い以下を追加。
> - **ログイン画面**（メール/パスワード → JWT、Phase 2-c）
> - **テナントスイッチャー**（Header 左: 現在テナント表示＋切替）
> - 車両ラベルは **display_name** を表示（内部は device_id/UUID）
> - 車両一覧・台数は**動的**（API 由来）。固定 3 台・固定色の前提を撤廃。マーカー色は device_id のハッシュから HSL 生成
> - 本書の旧記述（3色固定・台数固定）は上記を優先して読み替えること

## 1. UI の目的とユーザー

| ユーザー | 目的 | 重要度 |
|---|---|---|
| オペレーター／見学者 | 「今どの車がどこを走っているか」を一瞥で把握 | 最優先 |
| 開発者（自分） | デバイス・通信の動作確認（位置の正しさ、更新頻度、死活状態） | 次点 |

→ **地図が主役、UIは最小限**。管理画面のような複雑な操作は持たない。

## 2. 画面レイアウト

### デスクトップ

```
┌────────────────────────────────────────────────────────────┐
│ [ Header: ロゴ "carpal" / 接続状態 ● ]          (48px)      │
├──────────────────────────────────────────────┬─────────────┤
│                                              │  車両サイド   │
│                                              │  パネル      │
│                地図 (Leaflet)                 │  (260px)    │
│                                              │             │
│   ┌ 車両カード ────────────┐                  │ ┌─────────┐ │
│   │ ● car01  42.5 km/h →  │  ← 地図上フロート  │ │car01 走行│ │
│   └───────────────────────┘                  │ │car02 走行│ │
│                                              │ │car03 停止│ │
│   ┌──────────────────────┐                   │ └─────────┘ │
│   │ ⚖ズーム / 🎯現在地追従 │ 右下コントロール    │             │
│   └──────────────────────┘                   │             │
├──────────────────────────────────────────────┴─────────────┤
│ [ Footer: ©国土地理院 / 更新 3秒前 ]            (28px)      │
└────────────────────────────────────────────────────────────┘
```

### モバイル (≤768px)

- サイドパネルは**下から引き上げるボトムシート**に変形（折りたたみ可能、ハンドルで展開）
- ヘッダーは縮小（ロゴ＋接続状態のみ）
- 車両カードは地図上部に1行で重ねる

## 3. コンポーネント設計

### 3.1 Header

| 要素 | 内容 |
|---|---|
| ロゴ | `carpal`（テキストで十分） |
| MQTT接続状態 | ● 緑=接続 / ● 灰=再接続中 / ● 赤=切断。`mqtt.js` のイベントから反映 |
| 時計 | 現在時刻（開発時の時刻ずれ確認用） |

### 3.2 地図

| 項目 | 設計 |
|---|---|
| タイル | 国土地理院 淡色地図。車両を目立たせるため背景は淡色が最適 |
| 車両マーカー | ▲SVG divIcon。色は**デフォルトで device_id のハッシュから HSL 生成**（改訂注記参照）。以下の car01=青 などは旧固定色の例として残す |
| 回転 | CSS `transform: rotate()` + `transition: .8s linear` でスムーズ回転 |
| ラベル | マーカー直下に車両IDを常時表示（小さいフォント） |
| 軌跡 | 車両色のポリライン（直近100点、透過50%） |
| フォーカス動作 | 車両クリック → パン＋ズーム(15)して選択状態に。カードがポップアップ |
| 初期ビュー | セッション最初の位置受信時に**測位位置へ自動センタリング** (zoom 14)。表示範囲は localStorage (`carpal.view`) に保存し、次回オープン時に復元。復元できた場合は自動センタリングしない |

### 3.3 車両カード（地図上フロート / 選択時ポップアップ）

```
┌────────────────────────────┐
│ ● car01          [📌追従]   │
│ 速度  42.5 km/h            │
│ 方位  90° (東)              │
│ 最終更新 3秒前               │
└────────────────────────────┘
```

- **📌追従トグル**: ON にすると選択車両を `setView` で常時追従（運転見学時に便利）
- 最終更新が60秒超で「オフライン」表示に切替（グレーアウト＋●灰）

### 3.4 車両サイドパネル

全車両の一覧。各行 = 簡易ステータス。

```
┌────────────────────────┐
│ ● car01   走行中        │
│   42.5 km/h · 東へ      │
├────────────────────────┤
│ ● car02   走行中        │
│   25.0 km/h · 南西へ    │
├────────────────────────┤
│ ● car03   停止          │
│   0 km/h · 12分前更新   │
└────────────────────────┘
```

- 行クリック = 地図でその車を選択
- 「方位 → 八方位テキスト」（東・南西など）は方位角から変換
- 未登場車両（通信開始前）は薄表示で `car01〜03` を先に並べる → 「待機中」

### 3.5 Footer

| 要素 | 内容 |
|---|---|
| 帰属 | ©国土地理院（タイル利用規約上の帰属表示） |
| 更新間隔表示 | 直近の受信間隔（デバッグ用。通常は省略可） |

## 4. 状態設計（ステートモデル）

```
AppState {
  connection: 'connected' | 'reconnecting' | 'disconnected'
  vehicles: {
    [id]: {
      online: boolean          // status受信 or 60秒タイムアウト
      lat, lng, speed, bearing // 最新位置
      lastTs: number           // 最終受信時刻
      history: [LatLng]        // 軌跡 (最大100点)
      follow: boolean          // 追従ON
      selected: boolean        // 選択中
    }
  }
}
```

| イベント | 状態遷移 |
|---|---|
| `connect` | connection=connected、`carpal/+/status` 再購読（Retain で在線復元） |
| `close`/`reconnect` | connection=reconnecting、全車両を灰表示（位置は保持） |
| location 受信 | 該当車両の位置・速度・方位更新、history 追加、lastTs 更新 |
| status online:false 受信 | online=false（オフライン表示） |
| 60秒間 location 無し | online=false に補正（LWT取りこぼし保険） |
| 車両クリック | selected=true、地図が pan/zoom |
| 追従トグル | follow=true の間、当該車の location 受信毎に `setView` |

## 5. 視覚デザイン

| 項目 | 仕様 |
|---|---|
| 配色 | ベース白/淡灰、アクセントは車両3色: car01 `#1565c0` / car02 `#ef6c00` / car03 `#2e7d32`。状態色: 緑=走行 `#43a047`、灰=停止/オフライン `#9e9e9e`、赤=エラー `#e53935` |
| タイポ | システムフォント (`system-ui`)。数値は tabular-nums で桁ずれ防止 |
| マーカー | 34×34px の▲＋白フチ＋薄い影。ラベル11px bold、白縁取り |
| アニメーション | 位置は Leaflet 既定の補間＋回転は CSS transition。過剰なアニメはなし（「実用の見やすさ」優先） |
| ダークモード | Phase 2。地図タイルの切替（国土地理院白地図など）と合わせて後日対応 |

## 6. 実装上の注意

- 国土地理院タイルの帰属表記は利用規約上必須 → Footer に常時表示
- `ws://` vs `wss://` は `location.protocol` から自動判定し、開発(LAN http)と本番(https)を両立
- Retain の status は接続直後に一括で飛んでくるため、`connect` 時に車両リストを初期化してから描画（ゴースト防止）
- 車両カード・パネルのDOM更新は location 受信毎だと3台×3秒で十分間に合うが、将来的に高頻度化するなら requestAnimationFrame バッチ更新に変更

## 7. 実装フェーズ

| 段階 | 内容 | 対応ファイル |
|---|---|---|
| M1 | 現状デモを本設計に寄せる（ヘッダー・サイドパネル・車両カード・3色分け） | `web/index.html`, `web/mqtt.js` |
| M2 | 選択・追従・軌跡のインタラクション | 同上 |
| M3 | モバイル対応（ボトムシート） | 同上 |
| M4 | ダークモード・履歴再生（Phase 2 バックエンドと共に） | 未定 |

M1〜M3 はフロントのみで完結（バックエンド不要）。M4 は Phase 2 の履歴保存とセット。
